How matching works

A profile rewrites HTTP headers on every request whose URL matches one of its patterns. Each pattern matches in one of two modes:

  • glob — declarativeNetRequest filter syntax. * matches any characters, | anchors the start or end, || anchors a domain. Example: https://api.example.com/*
  • regex — an RE2 expression matched against the whole URL. Backreferences and lookahead are unsupported, and regex rules draw on a smaller Chrome quota. Example: ^https://api\.(dev|qa)\.example\.com/.*

Every pattern in a profile shares that profile's headers. Leave a value empty to remove the header instead of setting it. Use the toggle on a row to park it without deleting it.

Diagnostics

Chrome's DevTools Network panel does not reliably show request headers modified by declarativeNetRequest. To confirm a header is really being sent, hit an echo endpoint such as https://httpbin.org/headers, or check your server logs.
